## Hướng dẫn triển khai lên GitHub Pages
1. Giải nén file ZIP này và tải toàn bộ 3 file (`index.html`, `logo.png`, `README.md`) lên repository GitHub của bạn (đảm bảo nằm cùng ở thư mục gốc).
2. Vào **Settings** -> **Pages** trên repository GitHub.
3. Ở mục **Build and deployment**, chọn Branch `main` (thư mục `/root`) và nhấn **Save**.
4. Truy cập đường link GitHub Pages được cấp để sử dụng trực tiếp trên trình duyệt (không cần cài đặt server).
